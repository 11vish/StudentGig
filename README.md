
# StudentGig – Freelance Marketplace for Students

StudentGig is a web-based freelance marketplace designed to connect college students with employers offering skill-based micro-tasks. It helps students discover opportunities, submit proposals, manage assignments, and build their professional reputation.

## Features

### Student Portal
- Student registration and login
- Browse and search available tasks
- Submit bids and proposals
- Track applications and assignments
- Manage profiles, skills, and portfolio
- View ratings and leaderboard rankings

### Employer Portal
- Post freelance tasks with budgets and deadlines
- Review student applications and proposals
- Assign tasks to candidates
- Review submitted work
- Rate completed assignments

### Admin Portal
- Monitor platform activity
- Manage user accounts
- Ban or unban users
- Moderate posted tasks

### Security
- Password hashing
- Session-based authentication
- Role-based access control
- Prepared SQL statements

## Technologies Used

- Frontend: HTML5, CSS3, JavaScript
- Backend: PHP
- Database: MySQL
- Local Server: XAMPP (Apache and MySQL)
- Database Management: phpMyAdmin
- Development Environment: Visual Studio Code

## Installation and Setup

1. Install XAMPP.
2. Copy the project folder into the `htdocs` directory.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Open phpMyAdmin in your browser.
5. Create the required database and import `setup.sql`.
6. Configure the database connection in `db.php` using your local MySQL settings.
7. Open the application in your browser using the appropriate localhost project path.

Ensure the database configuration matches your local environment before running the application.

## Project Purpose

StudentGig aims to provide a student-focused platform for discovering freelance opportunities, connecting with employers, and developing practical work experience.
